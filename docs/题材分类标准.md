| 项目 | 内容 |
|---|---|
| 文档名 | 题材分类标准 |
| 系统名 | AI_Story_Studio |
| 版本 | 0.2（用户 11-18 加了 7 个标签） |
| 编写日期 | 2026-11-18 |
| 修订 | 0.1：初稿；0.2：加 7 个标签（ABO、豪门世家、年上、失忆、蒸汽朋克、黑道、神话），见第 8 章 |
| 对应要件 | 01_要件定义书.md（1.3）FR-66～FR-70、C-12 |

本标准给写法库和藏书分类用，分三层：**频道 → 大类 → 标签**。它是题材词表（TBL-23）的来源。

各平台的分类各不相同，也会调整（C-12）。本标准依据的是起点中文网（含起点女生网）、晋江文学城、番茄小说、七猫小说在 2026-11-18 的分类页面，出处见第 7 章。平台没有公开判定规则的地方，本标准写明是「行业惯例」或「本工作室的约定」，不冒充官方。

---

## 1. 为什么这样分

- **频道**决定读者是谁、看的是什么快感：男频看升级、事业、冒险，女频看感情和成长，纯爱看男性之间的感情。各平台都是先分频道再分类。
- **大类**按世界观和时代分，例如玄幻、仙侠、都市、历史、古代言情。各平台都有这一层，只是叫法不同，本标准统一了叫法（第 3 章）。
- **标签**是套路和元素，例如重生、穿越、无限流、刑侦、娱乐圈。各平台有的把它做成二级分类、有的做成标签（如番茄把「快穿」「宫斗宅斗」做成一级），本标准统一当标签，一本书可以有多个。

## 2. 第一层：频道

| 频道 | 定义 | 依据 |
|---|---|---|
| 男频 | 主线是主角（通常是男性）的升级、事业、冒险、争霸；感情线有也是辅线 | 起点、番茄、七猫都有男频；男频一级分类按世界观和力量体系分〔A〕〔C〕〔D〕 |
| 女频 | 主线是女主角的感情、成长或家庭；或者女主视角为主、以女性读者为对象 | 起点女生网、番茄、七猫的女频一级分类普遍带「言情」〔A1〕〔C〕〔D〕；女频大致等于以女性读者为主的网文〔G〕 |
| 纯爱 | 主线是两位男性主角之间的感情关系（耽美） | 晋江书库按「性向」分出「纯爱」，单设纯爱分站〔B〕；起点、番茄、七猫的公开分类里没有纯爱大类〔A〕〔C〕〔D〕 |

**判别规则**（按顺序问，问到能定就停）：

1. **感情主线是谁和谁？**
   - 两位男性 → 纯爱；
   - 一男一女，且女主视角为主、感情是主线 → 女频；
   - 没有感情主线，或感情是辅线 → 看第 2 条。
2. **主线是什么？**升级、打怪、争霸、事业、破案、冒险为主 → 男频；女主的成长、家庭、宅斗、事业为主 → 女频。
3. **主角是谁、视角跟谁？**以上两条还定不了时，男主视角归男频，女主视角归女频。

说明：这三条是本工作室的约定。晋江公开的作品字段（性向、作品视角）支持第 1、3 条〔B2〕；第 2 条平台没有公开说明，是按各平台大类的结构推出来的行业惯例。

**特殊情况**

| 情况 | 怎么归 |
|---|---|
| 出版作品、平台出现前的作品（如金庸武侠） | 按上面的规则归（金庸归男频·武侠），另加标签「出版作品」。各平台把它们放在「出版」频道〔A〕〔D〕，但那是上架渠道，不是题材 |
| 无 CP（没有感情线）的作品 | 按第 2、3 条归男频或女频，加标签「无CP」。晋江书库有「无CP」性向〔B〕 |
| 百合（两位女性主角的感情线） | 本标准暂归女频，加标签「百合」；藏书里没有这类，以后遇到再定 |
| 纯爱和其他频道都像 | 以感情主线为准；感情线弱、主线是破案或升级的纯爱作品仍归纯爱，在大类和标签里体现主线（如「现代都市纯爱」＋「刑侦」） |

## 3. 第二层：大类

## 4. 第三层：标签

标签描述套路和元素，一本书可以有多个，一般 2–6 个。下表是第一批，以后加词照 BD-02-14 走「加词留记录」。

| 组 | 标签 |
|---|---|
| 时空套路 | 重生、穿越、快穿、无限流、系统流、穿书 |
| 职业和场景 | 刑侦、悬疑推理、娱乐圈、电竞、校园、职场、军旅、医疗、宫廷、江湖、门派、星际、末世、种田、经商、豪门世家、黑道 |
| 关系 | 师徒、青梅竹马、破镜重圆、相爱相杀、强强、年下、年上、救赎、先婚后爱、追妻、群像 |
| 风格和情绪 | 甜文、虐恋、爽文、轻松、正剧、暗黑、治愈、喜剧 |
| 元素 | 修仙、玄学、灵异、异能、机甲、虫族、武功、权谋、ABO、失忆、蒸汽朋克、神话 |
| 其他 | 无CP、百合、出版作品 |

标签和大类的分工：大类回答「这本书在什么样的世界里」，标签回答「用了什么套路、写什么样的关系」。例如「刑侦」在男频和纯爱里都可以是标签，大类分别是「悬疑灵异」和「现代都市纯爱」。

各平台标签的情况〔A2〕〔B2〕〔C〕〔D〕：起点的「重生、穿越、无限流、刑侦、种田、校园、末世、江湖、系统流」是标签，有官方释义；七猫和番茄把其中一部分做成了二级或一级分类；晋江的内容标签词库没有完整查到。

## 6. 拿不准时怎么处理

1. 每本书的分类都写**把握程度**：高（三条判别规则都清楚）、中（有一条要推断）、低（两条以上要推断，或者正文前后矛盾）。
2. 分类**依据**至少 2 条，必须是书里看得到的东西，写明章号：主角性别、视角、开篇发生了什么、主线是什么、感情线在哪几章出现。不能只凭书名或作者。
3. 把握程度为「低」、或依据少于 2 条的，进「交用户定」清单，用户定了以后写进分类表（TBL-27）的「用户结论」，以用户结论为准。
4. 两个大类都像时，选主线所在的那个当主大类，另一个记为次大类。
5. 遇到本标准没有的类和标签，不硬塞：记下来，交用户决定要不要加词（BD-02-14）。
