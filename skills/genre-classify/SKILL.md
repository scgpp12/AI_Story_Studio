# 题材分类

照 `docs/题材分类标准.md` 做。词只能用标准里的频道、大类、标签；标准里没有的词不要自造，写进「建议加词」。

## 要读什么

- 书的开头：文案或简介（如果有）、前 3 章；
- 中段抽 2 处，各几千字；
- 不要只看书名和作者下结论。

## 步骤

1. **频道**：按标准第 2 章的三问，按顺序问：
   1. 感情主线是谁和谁？
   2. 主线是升级、事业、冒险，还是感情、成长？
   3. 主角是谁，视角跟谁？
   
   问到能定就停，记下是哪一问定的。
2. **大类**：在该频道的大类表里选一个主大类。要是另一个大类也明显成立，记为次大类。
3. **标签**：从标签表里选 2–6 个，只选正文里确实出现的套路和元素。
4. **依据**：至少 2 条，每条写「第几章：看到了什么」。例如「第 1 章：开篇是男主在案发现场勘查」「第 3 章：两位男主角第一次正面冲突，此后感情线贯穿」。只写事实，不抄原文整句，引用不超过 12 个字。
5. **把握程度**：
   - 高：三问都有明确依据；
   - 中：有一问要靠推断；
   - 低：两问以上靠推断，或者前后矛盾。
6. **交用户定**：把握程度为低，或依据少于 2 条时，标「是」，并写出拿不准的是哪一点、两种可能分别是什么。

## 输出

只输出一个 JSON 对象：

```json
{"书名":"","频道":"男频|女频|纯爱","频道由第几问定":1,
 "主大类":"","次大类":"","标签":[],
 "依据":[{"章":1,"看到":""}],
 "把握程度":"高|中|低","交用户定":"是|否","拿不准的地方":"",
 "建议加词":[]}
```

## 不要做的

- 不凭书名、作者、平台印象分类。
- 不因为作品出版了就归「出版」频道；出版是上架渠道，在标签里写「出版作品」。
- 依据里不复述大段剧情，不抄原文整句。
