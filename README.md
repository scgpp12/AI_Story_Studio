# AI_Story_Studio

用本地大模型写短剧剧本和长篇小说的写作辅助系统。

写作之前，系统先从「写法库」里查出相关的规矩和技法，再从「故事圣经」里取出这部作品的人物、设定和伏笔。写完以后，按统一的评分表打分（每项扣分都要附原文证据），然后只改分数最低的几项。

本项目同时是一次企业开发流程的前期测试：从要件定义开始，每个工程都出正式文档，测试真跑。

## 四个部件

| 部件 | 管什么 |
|---|---|
| 写法库 | 跨作品通用的写法：规矩、技法、节奏、骨架、模板、评分项 |
| 故事圣经 | 一部作品的事实：人物、设定、伏笔、事件、关系、人物现状 |
| 流水线 | 立项、圣经维护、大纲、分场、写作、检查、修改七个角色接力 |
| 检查修改 | 打分、找证据、分级修改、复查 |

## 运行前提

- 局域网推理服务器一台（带大显存显卡），已有 OpenAI 兼容的本地推理服务和 Ollama。
- 写作模型 Qwen3.8 27B，向量模型 bge-m3。
- Python 3.12，只用标准库、numpy、SQLite。
- 服务器地址等写在本地 `.env`，不进仓库（见 `.env.example`，实现阶段补）。
